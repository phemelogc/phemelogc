## Featured Project — SafeText

An anti-smishing mobile app built to detect SMS-based scams targeting Botswana users. Final year capstone project, built end-to-end:

- **Flutter (Android)** frontend with SMS Retriever API integration
- **FastAPI** backend deployed on **Railway**
- A multi-label **ML classifier** (Logistic Regression + TF-IDF) detecting phishing, urgency tactics, credential harvesting, impersonation, and localized Setswana scam patterns
- **Firebase Firestore** database with a 3-tier sender reputation system
- A React + Tailwind **admin dashboard**, built independently
